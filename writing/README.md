## The five rules if you read nothing else

1. **Start with the reader's goal.** First line: what this page helps them do.
2. **Answer first, details after.** TL;DR, then steps, then background.
3. **One idea per paragraph, one action per step.**
4. **Show real examples** that work when copy-pasted.
5. **Name things consistently.** The same term for the same concept, everywhere ([glossary](../foundations/glossary.md)).
